INSTALL

装上录音工牌

在电脑 Chrome 或 Edge 中打开此页，用 USB 数据线连接工牌。关闭串口监视器等占用设备的程序。

首次安装会替换原固件，合并镜像会覆盖 NVS 配网和网盘授权。需要保留配置时，请确认兼容性并选择仅更新应用。勾选擦除会清空本地录音、照片和配置。

请使用支持 Web Serial 的电脑浏览器。需要通过 HTTPS 或 localhost 打开此页。

安装完成后关闭烧写对话框，等待工牌重启，再进行下方配网。若连接失败，检查数据线并关闭其他串口程序后重试。

固件下载与版本校验

发布固件包含作者的百度应用配置；源码不包含真实应用 Secret。用户仍需扫码授权自己的百度网盘。自行编译时可使用自己的应用凭据。

CONNECT

通过 USB 配置 Wi-Fi

连接工牌后，输入可用的 2.4 GHz、有密码的 Wi-Fi。密码仅经 USB 发送到工牌；此页面不上传密码，也不保存密码。配网前先停止录音或回放。

请先连接 USB 工牌。

显示“已连接”与 IP 地址才表示成功。失败时检查密码、距离和频段后重试；换网时重新填写并保存。也可在工牌“无线网络”菜单扫描并配网。

GET STARTED

开始记录

  1. 配网成功后，短按 OK 打开菜单，进入“网盘文件”，用手机扫描工牌二维码并授权百度网盘。
  2. 主页长按 OK，或同时按下键与 OK，开始录音；录音中长按 OK 停止。每分钟自动保存并后台上传，停止后保存最后一段。
  3. 在百度网盘的应用录音日期目录中找到文件，再使用库库 AI 转写或摘要。断网时保存并停止，网络恢复后补传；要继续录音需再次按键。
  4. 子页面长按 OK 返回；主页长按下键熄屏，任意键唤醒。
