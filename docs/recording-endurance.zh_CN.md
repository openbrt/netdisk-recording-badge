# 连续录音续航

**满电、网络连接正常、边录边上传时，预计可连续录音约4小时。**

此估算对应 2026-10-06 测试的上传修正版固件，根据电量曲线得出，尚非从满电开始连续录音4小时的直接实测。不能将该结果套用于原已发布的 0.4.4 镜像。

## 本次测试确认的结果

| 结果 | 依据 |
| --- | --- |
| 连续录音实测下限 | 从 **71%** 电量开始，至少 **2小时48分13秒**；实际采集与写入 PCM 计数一致 |
| 网盘完整录音 | **168 个一分钟 WAV 文件**，合计 **2小时48分**；末尾七个完整文件下载后通过 WAV 格式、帧数和时长检查 |
| 满电到显示 0% | 线性外推 **约3.8小时**，取整约4小时；不是实测关机时长 |
| 满电并保留 10% 电量 | **约3.4小时**，模型敏感性范围 **3.2–4.4小时**；该范围不是统计置信区间 |
| 电池测试终点 | 测试者确认没电关机；精确关机时刻和最后未闭合段未能恢复 |

估算使用超过162分钟的合格样本，样本覆盖约97.5%，并通过采集器原有的进度、负载稳定与斜率一致性检查。此前 USB 供电录音、人工停录和待机耗电均已排除。最后有效样本仍显示录音与 Wi-Fi 正常，没有报告采集停止或遥测队列丢样；没有将后续遥测缺失视为关机证明。

## 测试条件与固件身份

- Wi-Fi 持续连接，采集同时将完整录音上传百度网盘。
- 音频为 16 kHz、16 bit、单声道 PCM，保存为 WAV，每分钟分段。
- 启动背光短暂为100%，随后稳定在15%；估算排除了切换区间。
- 启用了私有无线续航诊断。亮度、网络与上传延迟、电池状态或负载变化均可能改变时长。
- 固件内部版本仍为 `0.4.4`；应通过哈希识别本次测试修订，不能只看版本字符串。

## 尚未确认的范围

满电到关机的直接测试、最终精确时长、最后未闭合段恢复、全程下载内容核验及跨分段听感仍待验收。约4小时是上述条件下的估算，不是保证下限或绝对最大时长。断网、上传跟不上而填满暂存空间均可能使录音提前停止。
