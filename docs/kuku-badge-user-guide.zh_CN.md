# 网盘录音工牌操作指南

本指南对应工牌内“操作指南”菜单。中间的按键在屏幕上称为“OK”。功能或按键行为变化时，应在同一次迭代中更新本文件、英文版与屏上指引。

## 基本操作

- 熄屏时先按任意键唤醒，这次按键只唤醒屏幕。工牌主页短按 OK 键打开菜单；上下键选择，OK 键进入。子页面长按 OK 键返回。
- 菜单里的“操作指南”共五页，页码显示在内容框上方；按下键看下一页，按上键看上一页，长按 OK 键返回主页。翻页提示显示在内容框内，每行只说明一个操作或状态。
- 顶栏依次显示无线网络、网盘、录音与电量状态。录音时显示低调的圆点图标，主页显示本次持续录音时长。
- 主页长按下键熄屏；任意键唤醒。

## 录音

- 任意页面或熄屏状态，同时按下下键和 OK 键，请求开始录音。主页长按 OK 键也可请求录音。
- 开始前工牌检查无线网络和网盘可用性；无法连接时给出提示，不开始录音。已有上传任务时复用当前网络/授权状态。录音中断网时保存当前段并停止；网络恢复后只补传已保存文件，需要再次按键才能开始新录音。
- 录音与上传可以同时进行：后台只上传已保存的录音，正在录制的文件不会被上传。待传文件或正在上传不会阻止新录音。至少需有 256 KB 空间才能开始；空间不足时提前保存并停止，提示“暂存空间不足，已保存”，不会覆盖未上传录音。
- 录音中长按 OK 键停止。录音每 60 秒自动保存为一段，并在后台上传；切段不需要重新按键，麦克风采集持续进行。手动停止后保存不足一分钟的最后一段；网络中断时待恢复后补传。文件页根目录把本地待传文件置顶并显示状态。
- 上传录音按开始录制时的北京时间，存入 `/apps/网盘录音工牌/YYYY-MM-DD/`，补传仍保留原日期。未校时的 `REC` 文件归入 `undated/`；已有根目录文件不搬迁。
- 在百度网盘库库 AI 中选择录音进行转写或摘要；可用日期目录定位一批录音，再说明要处理的文件。持续录音没有两分钟总时长上限；能持续多久取决于电量、网盘服务和上传速度。断网时停止并保存；上传长时间跟不上、暂存空间不足时也会安全停止。没电中断后，下次启动会尝试修复最后未闭合的录音。2026-10-06 上传修正版从71%电量开始，验证连续采集与写入至少2小时48分13秒，网盘保存168个完整分段。在本次15%背光条件下，满电、网络正常、边录边上传时，预计可连续录音约4小时；这是电量曲线估算，尚非4小时直接实测。固件身份、条件与限制见[续航结果](recording-endurance.zh_CN.md)。精确关机时刻、最后未闭合段恢复、实际断网行为和跨分段听感仍待验收。

录音改用较小的读写块，仍保留 256 毫秒音频队列；显示刷新使用较小条带，为安全上传留出内存。WAV 格式和每分钟分段保持一致。每段确认上传成功后立即清理其本地暂存，后续文件仍在传输也不阻塞回收；排队的批次复用同一个上传任务。上传正文卡住时关闭连接并重试：写入轮询及套接字发送超时设为三秒，正文流式传输设有 40 秒预算；连接建立和云端响应另外等待。持续上传过慢仍可能耗尽暂存并安全停录。网盘批量上传期间，诊断遥测排队等待。USB 的 `STATS` 可查看实际采集/写入进度、固件身份、空闲内存和任务栈余量。`STATS` 还保留上传尝试计数、最后失败的阶段与耗时，直到重启；插回 USB 后可查看已恢复的故障。阶段编号为 1 目录、2 哈希、3 预创建、4 分片传输、5 云端合并、6 本地同步标记。USB 命令一直组装到换行，支持跨 USB 数据包的长命令。

## 录音续航测试

- 此可选诊断每次开机默认关闭。电脑通过 USB 执行 `ENDURANCE ARM <url> <token>` 配置私有局域网后台，配置只保存在 RAM。`ENDURANCE STATUS` 显示待触发阶段和后台确认序号，不打印密钥；`ENDURANCE OFF` 停止遥测而不停止录音。更换后台地址/密钥须重启工牌。流程见[测试方案](development/engineering/recording-endurance-test-plan.zh_CN.md)。
- 连接保持唤醒的电脑，等待后台显示 `ready_to_unplug` 后，完全拔下 USB 数据线。主机断开稳定五秒后，工牌通过 Wi-Fi 上报。拔线不会自动开始录音；未在录音时仍用原有录音手势开始。遥测不唤醒屏幕、不改变亮度。
- 每十秒采集电量百分比/电压及录音进度，约每分钟批量发送。后台按原采样时间处理重试，仅在电量趋势满足质量门槛时推估剩余/满电时长。结果是包含遥测负载的外推，不是实测关机时间。缺失上报标记为过期，不能当成电池耗尽。
- USB 主机检测不检测充电器供电；电脑休眠或数据断开可能模拟拔线。保持电脑唤醒和后台 Wi-Fi 可达。实际拔线后持续录音及估算准确度须分别实机验收。侧边充电灯尚未实现程序录音提示。

## 网盘文件与图片

- 菜单进入“网盘文件”。未授权时按屏幕提示扫码授权；已授权时浏览文件，按修改时间倒序排列。选中日期文件夹按 OK 进入，长按 OK 返回上级；在根目录长按 OK 返回主页。
- 浏览成功后列表保持不变，不定时刷新打断选择；需要读取新增文件时，返回后重新进入该目录。读取失败仍会自动重试。
- 上下键选择文件；长按上下键可快速移动。选中本地录音后按 OK 键可回放；回放时按 OK 键停止，上下键调音量。
- 选择 JPG 图片后可查看；工牌按比例缩放，让整张图片完整显示在接近屏幕全宽的预览区域，顶栏状态仍可见。查看时短按 OK 键把当前图片保存为工牌照片；长按 OK 键返回文件列表。
- 如果图片是网盘客户端生成的分享二维码，工牌展示的是该图片本身。别人用手机相机扫码后能否下载，由二维码中的分享链接及网盘端权限、有效期决定。
- 其他网盘文件目前只显示示例分享二维码；正式通用分享仍需项目作者完成服务认证。

## 重置网盘连接

- 菜单进入“重置网盘连接”。默认选择“取消”，上下键改选“确认重置”，短按 OK 执行；长按 OK 返回。
- 重置只清除工牌本地保存的网盘授权与文件列表缓存，保留 Wi-Fi、工牌照片、本地录音和网盘文件。它不会撤销百度账号端对应用的授权。
- 录音、回放或文件传输/加载中拒绝重置，请完成后重试；正在等待扫码的授权会安全取消。看到“连接已重置”后，短按 OK 打开新二维码，用手机重新授权。授权后二维码自动消失，进入网盘文件列表。

## 无线网络

- 菜单进入“无线网络”，按 OK 键扫描附近网络。选中网络后在屏上键盘输入密码，长按 OK 键连接。
- 不连接时，用上下键选“<”并按 OK 清空已输入内容；密码为空后再选“<”按 OK 返回扫描列表。长按 OK 是连接操作，不能用于取消。扫描页长按 OK 返回并恢复已存网络连接。
- 工牌记忆多个连接过的网络，运行时自动回连。无线网络页按下键查看已存网络；列表只显示保存的网络，不超过六条时从顶部开始显示。选中后按 OK 键进入删除确认页，再按 OK 键删除；在确认页长按 OK 取消，保留该网络。

被动 NFC 标签独立于屏幕和录音固件；门禁兼容性取决于门禁系统是否接受标签自身的标识和协议。
